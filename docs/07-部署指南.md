# Career OS 免费部署指南

## 1. 三个账号分别是什么

### 1.1 Supabase 项目

Supabase 是免费的云数据库 + 登录认证 + 文件存储服务。

- 官网：https://supabase.com
- 你要做的是：注册账号，创建一个 Project（项目），项目本身就是一套免费的 PostgreSQL 数据库。
- 本项目使用它的三样能力：
  - PostgreSQL：存用户、技能、路线、学习、岗位、面试、简历等全部数据
  - Auth：邮箱 + 密码登录，签发 JWT
  - Storage：保存项目文件、面试音频、头像
- 创建后你会得到三个关键值：
  - Project URL（形如 `https://xxxx.supabase.co`）
  - anon key（前端用）
  - service_role key（后端用，只能放服务端）

### 1.2 Vercel 账号

Vercel 是免费的 Next.js 前端托管平台。

- 官网：https://vercel.com
- 你要做的是：注册账号，把本项目 GitHub 仓库导入 Vercel，它会自动构建并部署前端。
- 免费方案会得到一个 `xxx.vercel.app` 域名，不需要自己买域名。
- 本项目前端部署在这里，环境变量里把 API 地址指向 Render 的 API 服务。

### 1.3 Render 账号

Render 是免费的云后端托管平台。

- 官网：https://render.com
- 你要做的是：注册账号，用仓库里的 `render.yaml` 创建服务，部署 FastAPI 后端。
- 免费方案会得到一个 `xxx.onrender.com` 地址，不需要自己买域名。
- 免费实例空闲 15 分钟后会休眠，第一次访问可能慢 30-60 秒，本项目前端已做自动重试。

## 2. Supabase 配置步骤

1. 打开 https://supabase.com 注册并登录。
2. 点击 New project，填写项目名（如 `career-os`）和数据库密码，选择离你近的区域。
3. 创建完成后进入项目控制台。
4. 打开 SQL Editor，把 `infra/supabase/migrations/0001_init.sql` 全部内容粘贴执行。
   - 这会创建 RLS 策略、Auth 注册触发器、Storage 桶和种子数据。
5. 打开 Authentication -> Providers -> Email，确认 Email 登录开启。
6. 打开 Settings -> API，复制：
   - `Project URL`
   - `anon public` key
   - `service_role` key
7. 打开 Settings -> API -> JWT Settings，复制 `JWT Secret`（后端校验登录用）。

## 3. Render API 配置步骤

1. 打开 https://render.com 注册并登录。
2. 点击 New -> Blueprint，选择本项目仓库，Render 会自动读取 `render.yaml`。
3. 在 Blueprint 中为 `career-os-api` 填写以下环境变量：

| 变量 | 值 |
| --- | --- |
| APP_ENV | production |
| DATABASE_URL | Supabase 的 Postgres 连接串（Database Settings -> Connection string） |
| XFYUN_API_KEY | 讯飞 APIKey |
| XFYUN_API_SECRET | 讯飞 APISecret |
| XFYUN_APP_ID | 讯飞 APPID（如 a1ff432b） |
| SPARK_MODEL | Spark-Lite |
| SPARK_WS_URL | wss://spark-api.xf-yun.com/v1.1/chat |
| SPARK_DOMAIN | lite |
| SUPABASE_JWT_SECRET | Supabase JWT Secret |
| TAVILY_API_KEY / EXA_API_KEY / GOOGLE_SEARCH_API_KEY / GOOGLE_SEARCH_CX / BING_API_KEY / GITHUB_TOKEN / YOUTUBE_API_KEY | 按需填写搜索 Provider 密钥 |

4. 部署完成后记录 `https://career-os-api.onrender.com`（实际地址以 Render 为准）。
5. 访问 `/health` 应返回 `{"status":"ok"}`。
6. 首次发布前在 Render Shell 或本地执行数据库迁移：

```bash
cd apps/api
uv run alembic upgrade head
```

## 4. Vercel 前端配置步骤

1. 打开 https://vercel.com 注册并登录。
2. Import Repository，选择本项目仓库。
3. Framework Preset 选择 Next.js。
4. 填写环境变量：

| 变量 | 值 |
| --- | --- |
| API_UPSTREAM | https://career-os-api.onrender.com |
| NEXT_PUBLIC_SUPABASE_URL | Supabase Project URL |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | Supabase anon key |

5. 点击 Deploy。完成后访问 `https://xxx.vercel.app`。

## 5. 密钥安全

- 所有密钥只放在部署平台的环境变量里，不写入代码。
- 本地 `.env` / `.env.local` 已被 `.gitignore` 排除，不会提交。
- `service_role` key 和 `SUPABASE_JWT_SECRET` 只能出现在后端环境，不能出现在前端。

## 6. 常见问题

### Render 冷启动

免费实例休眠后首次请求较慢，属正常现象；前端已自动重试并提示。

### 登录后没数据

确认已经运行过 `infra/supabase/migrations/0001_init.sql`，且注册用户会通过触发器自动创建 profiles 行。

### 讯飞星火报鉴权错误

确认 `XFYUN_API_KEY`、`XFYUN_API_SECRET`、`XFYUN_APP_ID` 三项都已配置，且模型名与账号开通的版本一致。

特别提示：**Spark Lite 在 2024 年 10 月升级后 domain 由 `general` 变更为 `lite`**。若报 `AppIdNoAuthError`，检查 `SPARK_DOMAIN` 是否与 `SPARK_WS_URL` 版本配套：

| 模型 | SPARK_WS_URL | SPARK_DOMAIN |
| --- | --- | --- |
| Spark Lite（免费） | `wss://spark-api.xf-yun.com/v1.1/chat` | `lite` |
| Spark Pro | `wss://spark-api.xf-yun.com/v3.1/chat` | `generalv3` |
| Spark Max | `wss://spark-api.xf-yun.com/v3.5/chat` | `generalv3.5` |
