状态：待确认

范围：免费版 / 中文优先 / 网页端 + 移动端（响应式 + PWA）/ 亮暗双主题

本阶段定义设计系统、布局体系、全部页面规格、核心组件、动效、暗色模式、移动端适配与视觉验收标准。Step 6 将据此搭建 Next.js 前端。

---

## 1. 设计目标与原则

参考 Linear、Notion、Stripe Dashboard、Vercel、Raycast 与 Apple HIG，但以工作台体验为主：

1. 安静高效：白色背景、低饱和、克制阴影，信息密度优先。
2. 少即是多：一个页面只突出一个主行动，AI 能力集中放置。
3. 数据可视化：图表服务于决策，不做装饰。
4. 一致响应式：同一组件在桌面、平板、手机上保持结构一致。
5. AI 可见：AI 生成内容始终标记来源，流式输出有明确状态。
6. 无障碍优先：键盘可操作、焦点可见、对比度达标。

禁止事项：

- 不使用营销式大 Banner、Hero 卡片、渐变背景、装饰性光斑。
- 不使用紫色主导配色、暗蓝灰单色主导或暖棕单色主导。
- 卡片不嵌套卡片，页面区块不使用漂浮卡片包裹。
- 不使用手绘 SVG 图标，统一 lucide 图标 + Tooltip。

## 6. 动效规范

| 场景 | 动效 |
| --- | --- |
| 页面切换 | 200ms fade + 8px 上移 |
| 列表进入 | stagger 30ms，fade + 4px 上移 |
| Drawer / Dialog | 220ms 平移 + fade，spring 阻尼 |
| 拖拽排序 | Framer Motion layout，drop 后回弹 |
| AI 流式 | 光标 800ms 呼吸动画，不阻塞滚动 |
| 录音 | 波形 60fps canvas 实时绘制 |
| Toast | 150ms 滑入，自动消失 |
| 图表 | ECharts 默认过渡，时长 500ms |

`prefers-reduced-motion` 下禁用位移与呼吸动画，仅保留淡入淡出。

## 7. 暗色模式

- 使用 next-themes + class 策略，跟随系统并允许手动切换。
- 所有颜色走 CSS 变量，组件不写死色值。
- 图表在主题切换时更新色板，禁用白闪。
- 暗色扫描清单：背景对比、边框可见、阴影减弱、AI 标识色不刺眼。

## 8. 响应式与移动端

| 断点 | 布局 |
| --- | --- |
| < 768px | 单列 + BottomNav + 全屏 Sheet |
| 768-1279px | 图标 Sidebar + 两栏 |
| >= 1280px | 完整 Sidebar + 多栏 |

移动端专项：

- 触控目标不小于 44px。
- 表单使用移动端键盘类型（number / email / url）。
- 语音面试在移动端优先全屏录音面板。
- 图表隐藏次要图例，使用可滚动容器。
- 文本不超出父容器，长 URL 截断为单行省略。

---

## 9. 无障碍

- 文本与背景对比度达到 WCAG AA。
- 所有图标按钮有 aria-label 与 Tooltip。
- 焦点环使用 2px primary，键盘可达全部交互。
- AI 流式开始 / 完成时向屏幕阅读器播报。
- 表单错误通过 aria-describedby 关联。
- 模态与 Drawer 支持焦点圈闭与 Esc 关闭。

---

## 10. 视觉验收清单

- 页面首屏即进入实际功能，无营销文案区块。
- 亮暗主题下均无重叠文本、截断异常、卡片内卡片。
- 全站不出现紫色渐变、光斑、装饰性 SVG。
- 固定组件尺寸稳定，内容变化不跳动。
- 360 / 768 / 1280 / 1440 宽度截图检查通过。
- 图标按钮全部有 Tooltip。
- 所有 AI 产物有“AI 生成”标识。
- 移动端 BottomNav 5 项无溢出，安全区处理正确。

## 11. 已确认决策（Step 5 评审结论）

1. 品牌标识采用“Career OS”文字标志 + 成长循环几何图标，暂不做复杂品牌 Logo。
2. 移动端以“响应式 Web + PWA”交付，可安装到主屏幕；原生 App 后续再评估。
3. 界面支持中英文双语（zh-CN / en），默认跟随浏览器语言，设置页可手动切换。

## 12. 品牌图标资产

### 12.1 设计概念

图标表达 Career OS 的核心循环：外圈代表 Learn -> Practice -> Build -> Interview -> Job -> Promotion 的成长闭环，内部三根递增柱代表技能成长，顶部节点代表职业目标。

### 12.2 资产清单

| 文件 | 用途 |
| --- | --- |
| career-os-mark.svg / png | 独立图标，侧栏、登录页、浏览器标签 |
| career-os-appicon.svg / png | PWA / App 图标，蓝色圆角底 + 白色标识 |
| career-os-logo-light.svg / png | 亮色界面横版 Logo |
| career-os-logo-dark.svg / png | 暗色界面横版 Logo |

资产目录：docs/design/

### 12.3 使用规范

- 主色 #2563EB（亮色）/#3B82F6（暗色），成长节点使用 #16A34A / #4ADE80。
- 图标最小尺寸 20px，横版 Logo 最小高度 24px。
- 不拉伸变形、不加阴影、不替换颜色、不叠加文字。
- 亮色界面用 light Logo，暗色界面用 dark Logo。

### 12.4 设计来源说明

本图标为矢量方案，由代码生成 SVG 并渲染 PNG，未使用 AI 位图生成。若后续需要 AI 位图变体（拟人化 / 3D 风格等），可再走 imagegen 生成。
